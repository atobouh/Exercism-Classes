VLAN trunks

        
A switch port normally belongs to one VLAN. That is fine for a PC, but the link between a switch and a router has to carry many VLANs at once. That link is a trunk.

        
On a trunk, every frame carries a 4-byte 802.1Q tag holding its VLAN ID. The receiving device reads the tag, removes it, and treats the frame as part of that VLAN. One VLAN, the native VLAN, crosses untagged.

        
A router can route between VLANs over one trunk by giving each VLAN its own subinterface. Each subinterface accepts one tag and owns the gateway address for that VLAN.

        

          remember
          Access portone VLAN, frames untagged
          Trunkmany VLANs, every frame tagged
          Router-on-a-stickone subinterface per VLAN
        

        
interface GigabitEthernet0/0/1.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

What I took, from whom, and why it works

    

      
Your Python app
reference you shared
Two panes, input and result, and one shortcut between them. Taken: config on the left, the live network on the right, Ctrl Enter to apply, a header that reports the run like a test runner.

      
Harry Beck, Tube map
1933, Massimo Vignelli in 1972
Beck chose topology over geography, with straight lines, 45 degree turns and colour per line, and it became the most copied diagram in the world. Taken: the network is a transit map. Each VLAN is a coloured line, a trunk is lines sharing track, devices are stations.

      
Falstad circuit simulator
falstad.com/circuit
Moving dots show current, so you see a closed loop instead of imagining it. Taken: traffic dots flow along the map all the time and stop at the exact point the network breaks.

      
Strudel live coding
music, TidalCycles
It highlights the part of the code that is making the sound right now, which ties notation to effect. Taken: while you watch a packet, the config line that decided each hop lights up in the editor.

      
Python Tutor, Bret Victor
"see the state", "follow the flow"
Learners understand code when they can see the data change step by step. Taken: watch the packet shows MAC tables, routes and tags changing per hop, marked new, like variables.

      
Lichess game review
chess
After a game you scrub every move with an evaluation graph and see where it turned. Taken: after a lab, every apply is a move, graded against the checks, with the one that fixed it marked best.

      
PhET simulations
University of Colorado
Implicit scaffolding: a few constrained controls guide exploration without instructions. Taken: each lesson has one control on a live network, here the VLANs allowed on the trunk.

      
Ableton Live
music
"Window management has nothing to do with being a musician." One window, no tools to switch, direct manipulation. Taken: no modal screens. Reading, editing, running and watching all happen in the same two panes.

      
Execute Program
spaced repetition for code
Reviews are small runnable examples, not trivia. Taken: review cards are tiny configs and show outputs you predict or complete.

      
3Blue1Brown
maths
One idea at a time, until you feel you could have invented it. Taken: lessons are three short paragraphs, one rule box, one live control.
