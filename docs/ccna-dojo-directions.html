How one cable carries many VLANs

An access port belongs to a single VLAN, so its frames need no label. A trunk carries frames from many VLANs over one link, so every frame has to say which VLAN it belongs to.

802.1Q solves this by inserting a four-byte tag between the source address and the EtherType. The far switch reads the twelve-bit VLAN ID, removes the tag and forwards the frame only to ports in that VLAN.

Exam noteThe VLAN ID is 12 bits, so 4,096 values, of which 1 to 4094 are usable.
