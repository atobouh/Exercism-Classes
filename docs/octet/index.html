One cable, many VLANs

CCNA 2, module 3, lesson 4

An access port carries one VLAN. A trunk carries all of them on the same cable, so every frame needs a label saying which VLAN it belongs to.

That label is the 802.1Q tag: four bytes added to the frame, holding a 12-bit VLAN number. The switch at the far end reads it, removes it, and delivers the frame only inside that VLAN.

The trunk's native VLAN is 1. How does PC-SALES's frame cross it?

The system

Octet borrows one thing from the world of networking and uses it everywhere: the colour code on the wires inside every cable. Layout, navigation and controls stay the ones you already know from good desktop apps.

Four pairs, four courses

The T568B pairs that every network engineer crimps: orange for CCNA 1, green for CCNA 2, blue for CCNA 3, brown for what comes after.

The wire is the progress bar

A white wire with a coloured stripe means you are learning it. A solid wire means mastered. If you start forgetting, it turns striped again. No points, no streaks.

Cat6 jacket blue

The shell is the colour of the patch cables in every lab. In the dark theme it deepens instead of disappearing.

Type

Funnel Display for titles, Funnel Sans for everything you read and click. Azeret Mono appears only where a device prints text: configs, addresses, the console.

The one signature move

Click any cable to strip its jacket and see the VLANs inside. One wire on an access link, several on a trunk. A failed check shows as a cut wire that closes when you fix it.

Your red lines

Nothing gamified. Lessons are two short paragraphs, then something to touch. Each screen does one job, with at most three areas. No label ever sits above a title.
