Every learning object is a file

.lessonA notebook: text, live diagrams, and config blocks you run in the simulatorCtrl Enter runs the block under the cursor
.demoA guided replay. The topology animates, a packet log fills in, each step is narratedSpace play, Left and Right step, then "your turn"
.topoA lab. Topology, device consoles, and checks that run like a test suiteType in consoles, Ctrl Enter runs dojo check
.drillA timed prompt that generates questions forever and tracks your speedType the answer, Enter submits
.reviewSpaced-repetition cards, scheduled from your forgetting curveSpace reveals, 1 to 4 grades
.faultAn incident ticket with evidence. Find the cause, fix it, verify. Scored on time and on how few lines you changedInvestigate in the console, Ctrl Enter verifies
.examA timed mock exam that mixes questions and simulator tasksNot in this prototype yet
